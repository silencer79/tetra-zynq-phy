## Overview

This repository implements the **TETRA (Terrestrial Trunked Radio) Physical Layer
and Lower MAC** as synthesizable RTL for the Programmable Logic (PL) of the
Xilinx Zynq-7020 SoC. The RF frontend uses the Analog Devices AD9361 transceiver.

The target platform is the **LibreSDR** board (Zynq-7020 + AD9361).

Upper protocol layers (Upper MAC, MLE, MM, CMCE) are intended to run in software
on the Zynq ARM Cortex-A9 processor (PS).

Reference standard: **ETSI EN 300 392-2** (TETRA V+D Air Interface).

## Platform

| Component | Specification |
|-----------------|--------------------------------------------------|
| FPGA | Xilinx Zynq-7020 (XC7Z020-CLG484) |
| RF Transceiver | Analog Devices AD9361 (70 MHz – 6 GHz, 2×2 MIMO)|
| Toolchain | Vivado 2022.2, Verilog-2001 |
| Simulator | iverilog + vvp |

## TETRA PHY Parameters

| Parameter | Value |
|----------------------|-------------------------------------|
| Modulation | π/4-DQPSK |
| Symbol rate | 18 ksym/s |
| Gross bit rate | 36 kbit/s (2 bit/sym) |
| Channel spacing | 25 kHz |
| Pulse shaping filter | Root Raised Cosine (RRC), α = 0.35 |

## Getting Started

### Prerequisites

- [iverilog](http://iverilog.icarus.com/) and `vvp`
- Python 3 (for test vector generation and `run_sims.py`)
- Vivado 2022.2 (for synthesis/implementation — optional for simulation)

### Clone

```bash
git clone --recurse-submodules https://github.com/silencer79/tetra-zynq-phy.git
cd tetra-zynq-phy
```

### Run simulations

```bash
# Generate test vectors
python3 scripts/gen_pi4dqpsk_vectors.py
python3 scripts/gen_reed_muller_vectors.py

# Run all testbenches
python3 run_sims.py
```

### Vivado synthesis

See `scripts/vivado_build.tcl` for the synthesis/implementation flow.

## Known Limitations

- **No hardware validation**: All results are from behavioral simulation only.
- `tetra_viterbi_decoder`: testbench timeout counter fires cosmetically (all TCs pass).
- `tetra_rx_frontend`: 34 sample comparison warnings due to fixed-point quantization
difference between Python reference model and RTL.
- `tetra_zynq_top` / `tetra_system_top`: no dedicated testbench (integration TB pending).
